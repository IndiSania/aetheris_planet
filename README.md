# Aetheris — Space Exploration Dashboard

A professional React JS interface for exploring planets, missions, and near-Earth objects.

## Tech Stack
- React JS
- Vite
- JavaScript (ES Modules)
- Lucide React
- CSS responsive tanpa UI framework

## Features
- Responsive dark-space dashboard
- Planetary atlas dengan detail modal
- Search celestial objects
- Mission control dengan progress monitoring
- Asteroid watch dashboard
- Interactive navigation tanpa reload
- Mobile navigation
- Clean component-based React structure

## Run locally
```bash
npm install
npm run dev
```

Build production:
```bash
npm run build
npm run preview
```

## Struktur
```text
src/
├── components/
├── data/
├── pages/
├── main.jsx
└── styles.css
```

Catatan: folder components/data/pages disiapkan untuk pengembangan lanjutan. Versi awal memakai komponen yang terorganisasi dalam `main.jsx` agar mudah dipahami dan langsung dijalankan.
